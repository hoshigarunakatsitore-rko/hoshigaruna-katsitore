# hoshigaruna-katsitore

3人共同の競馬予想・研究プロジェクト。

## Purpose

- 各メンバーがそれぞれの方法で予想・分析する
- ChatGPT上で分析結果を統合する
- 再利用可能なロジック、変換処理、ツールをGitHubで管理する
- 大容量データや原本はGoogle Drive側で管理する

## Roles

- GitHub:
  - code
  - schemas
  - adapters
  - tools
  - documentation

- Google Drive:
  - raw data
  - spreadsheets
  - analysis outputs
  - large assets

- ChatGPT Shared Project:
  - member rooms
  - integrated analysis
  - discussion support

## Data

JRDB等の一部データは個人管理環境を正本とし、
共有環境からは必要に応じて変換済みデータまたはツール経由で利用する。
